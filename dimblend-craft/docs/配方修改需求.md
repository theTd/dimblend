# Dimblend Craft — 配方修改需求文档

## 1. 背景与目标

`dimblend_craft` 是为整合包 **TrainTripWorld** 定制的配方调整 mod，运行于
**Minecraft 1.21.1（NeoForge 21.1.249，Create 6.0.10）**。

- 整合包位置：`E:\misc\TrainTripWorld`
- 目标：在不改动上游 mod 文件的前提下，于运行时对 **Create 及其附属 mod、TACZ（Timeless and Classics Zero）、森罗物语系列、哨兵机械臂** 的合成配方做批量修改与删除，用于整合包的平衡性调优。

## 4. 语义约定

- **替换**：将配方中该位置原有材料换成指定材料（数量沿用原位置数量，如原位置为空则视为新增）。
- **添加**：向该位置写入指定材料；若目标位置已有材料则覆盖，不允许出现一个位置双材料。
- **删除配方**：产物不再有任何合成获取途径（仅指合成台配方；冶炼、机械动力式的其他处理方式不在本次范围内，**3.4 铁轨除外，其序列组装配方一并删除**；3.9-3.13 明确列出的机器配方按其配方 ID 删除）。
- **产物数量改为 1**：仅改数量，材料布局不变。
- **机器配方修改**（3.9-3.13）：按配方 ID 对机器配方（搅拌、塑形、洗涤、烧炼、分馏、合金炉等）做字段级修改，只改列出的字段（产量、热度、产物 ID、概率、材料表），其余字段沿用上游原值。
- **新增配方**（3.9-3.13 中 `dimblend_craft:` 命名空间）：由本 mod 随包数据提供的全新配方，带 `neoforge:mod_loaded` 条件，目标 mod 缺失时自动跳过。
- **排序**：调整配方在 RecipeManager 最终列表中的先后（把目标配方移到锚点配方之前），用于同材料、不同热度的机器配方共存时决定命中优先级；材料布局与产物均不变。
- **前缀匹配修改**（3.15）：按配方 ID 前缀匹配并做字段级修改，用于上游动态注入、数量随上游数据变化的配方系列；只改列出的字段，其余字段沿用上游原值。

## 5. 已确认决议（需求冻结）

以下三项已由需求方拍板，实现时按此执行：

1. **潜影盒**：蓄电池配方位置 5 使用 tag（`c:shulker_boxes` 或运行时等价 tag）兼容任意颜色的潜影盒。

## 2026-10-31 黄铜改为仅超级加热

- 需求方口径：**仅超级加热能加工黄铜**。3.9 原「加热版产量 2→1 + 超热版排序优先」的共存方案取消，
  改为**删除** `create:mixing/brass_ingot`。
- 原因（Create 6.0.10 源码核实）：`HeatCondition#testBlazeBurner` 中 `HEATED` 判定为
  `level != NONE && level != SMOULDERING`，SEETHING 同样通过；两条同材料配方并存时
  `BasinOperatingBlockEntity#getMatchingRecipes`（第 180 行）按材料数降序**稳定**排序、
  并列保持 `RecipeTrie` 取出序。排序只能决定超热火下命中哪条，**不能阻止加热火命中加热版**。
