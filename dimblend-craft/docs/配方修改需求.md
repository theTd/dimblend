# Dimblend Craft — 配方修改需求文档

## 1. 背景与目标

`dimblend_craft` 是为整合包 **TrainTripWorld** 定制的配方调整 mod，运行于
**Minecraft 1.21.1（NeoForge 21.1.249，Create 6.0.10）**。

- 整合包位置：`E:\misc\TrainTripWorld`
- 目标：在不改动上游 mod 文件的前提下，于运行时对 **Create 及其附属 mod、TACZ（Timeless and Classics Zero）** 的合成配方做批量修改与删除，用于整合包的平衡性调优。

## 4. 语义约定

- **替换**：将配方中该位置原有材料换成指定材料（数量沿用原位置数量，如原位置为空则视为新增）。
- **添加**：向该位置写入指定材料；若目标位置已有材料则覆盖，不允许出现一个位置双材料。
- **删除配方**：产物不再有任何合成获取途径（仅指合成台配方；冶炼、机械动力式的其他处理方式不在本次范围内，**3.4 铁轨除外，其序列组装配方一并删除**）。
- **产物数量改为 1**：仅改数量，材料布局不变。

## 5. 已确认决议（需求冻结）

以下三项已由需求方拍板，实现时按此执行：

1. **潜影盒**：蓄电池配方位置 5 使用 tag（`c:shulker_boxes` 或运行时等价 tag）兼容任意颜色的潜影盒。
2. **铁轨删除范围**：删除 Steam 'n' Rails（`railways`）**自有铁轨**的合成配方 **+ 序列组装配方**，原版 `minecraft:rail` 配方保留不动。
3. **植物油删除范围**：删除 `createdieselgenerators:plant_oil` 流体的**全部获取途径**，包括机器配方（搅拌/混合等）与植物油桶物品配方。
