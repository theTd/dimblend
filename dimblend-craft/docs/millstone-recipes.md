# 森罗石磨配方精简（2026-10-17 甲方确认）

仅精简森罗物语石磨：禁止纯染料配方、精妙背包及升级模块拆解。
机械动力小石磨的配方、产物和加工时间均不改，不做森罗到 Create 的配方同步。

- 纯染料检查所有可能产物，包括概率副产物；只要有非染料产物便保留，例如甜菜的种子副产物。
  染料按 DyeItem 或 `c:dyes` 判断；空产物和零概率项不计。
- 精妙背包拆解按所有输入候选均来自 `sophisticatedbackpacks` 判断，覆盖背包与升级模块。
  不按配方命名空间判断：整包 57 条拆解配方实际位于 `create:milling/*`。
- 森罗原生禁配方不参与匹配，避免挡住 Create 的合法混合产物（如甜菜带种子配方）。
  原生匹配与 Create 兜底之后再统一过滤；整包 JEI 的列表入口使用相同规则。
  不删除或改写 RecipeManager 中的配方，因此 Create 小石磨及其他加工设备不受影响。
- 本次展示兼容范围为整包现有 JEI；REI/EMI 仅在客户端世界存在时经过该入口，
  未覆盖它们在无世界时注册原生配方的路径，不承诺完整兼容。
- 兼容森罗厨房 1.4.1，缺少森罗时由既有 mixin plugin 跳过。

本功能由 `dimblend_craft` 提供；多人游戏服务端负责加工限制，客户端负责配方展示，应双端更新。

现有 `RecipeEdit` 管线继续负责数据包配方的删改；森罗从 Create 动态生成的兜底条目不在该管线中，
故在本模块增加限定于森罗的匹配与列表过滤，避免全局删除 Create 配方或跨模块依赖。
