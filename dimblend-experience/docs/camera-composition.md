# 相机照片构图兼容

适用 Camerapture 1.10.12，兼容代码只在该模组存在时加载。

- 新拍照片按屏幕中央最大 4:3 矩形裁剪，不拉伸；取景框外框显示实际拍摄范围。奇数分辨率为保持精确 4:3，最多另裁掉数个边缘像素。
- 旧照片文件保持不变。放入普通或发光展示框后，以 UV 居中裁剪为 4:3，画面宽 14/16 方块，露出原生边框。竖图和方图会裁掉上下部分。
- 拍摄调用从帧末提前到世界及后处理完成、普通 GUI 绘制前，复用 Camerapture 自身的截图、上传、缓存和相机状态恢复流程。原有帧末回调因一次性标志已清除而不重复拍摄。
- 上传现有文件和普通 F2 截图不经过该裁剪逻辑。Camerapture 自带的可选保存截图仍为原始全屏尺寸。
- GUI 阶段及之后绘制的界面不会进入新照片；世界渲染阶段的实体名牌、调试标记等仍可能保留，本改动不会屏蔽它们。

验证需覆盖横屏及竖屏/奇数窗口尺寸、相机缩放、普通及发光展示框、展示框旋转与墙/地/顶朝向；还需实机触发拍摄，验证一次拍摄仅生成一次上传且照片不含后续 GUI 覆盖。纯数学测试只验证构图与裁剪像素，不能替代 mixin 功能路径验证。
