# z256 提示条需求文档（独立）

> 只管条的显示，不管扣血 / 回血。
> 扣血那套（过 256 扣生命上限、回 128 以内恢复）是另一套逻辑，与本条互不读写。
>
> 实测修订：2026-09-22 回程锁存口径作废，改为回程瞬时归零（转头前进即恢复，无记忆）。
> §3.2 回程锁存全文作废，§4 示例已同步。

## 1. 目标

用一个进度条替代之前的 bossbar，常驻显示当前到“下一个 256”的进度。条上数字显示 `z` 的绝对值。

## 2. 术语

- `|z|`：玩家坐标 `z` 的绝对值，取整显示。
- 分段：每 256 一段，`[0,256)`、`[256,512)`、`[512,768)`……以此类推。
- 段内进度：`(|z| % 256) / 256`，每段从 `0%` 重新算到 `100%`。
- 去程：`|z|` 相对上次检查变大或不变（每 10 tick 比较一次）。
- 回程：`|z|` 相对上次检查变小超过 0.5 格（防抖阈值，每 10 tick 比较一次；站立抖动不算回程）。

## 3. 显示规则

### 3.1 去程

- 进度 = `( |z| % 256 ) / 256`。
- 例：`|z|=16` 显示 `6.25%`；`|z|=300` 显示 `(300-256)/256 ≈ 17.2%`。

### 3.2 回程瞬时归零（实测修订，锁存口径作废，无记忆）

- 每 10 tick 采样一次：`|z|` 变小超过 0.5 格即回程（防抖阈值，站立抖动不算回程）。
- 显示：回程且 `into = |z| % 256 > 128` → `0%`；其余（去程任意位置、回程前半段）一律按 §3.1 公式。
  `|z|` 恰为 128 / `into` 恰为 128 时公式自然给出 `50%`，不用特殊处理。
- 转头即恢复：去程当刻立刻按公式显示，不保留任何锁存状态。

### 3.3 颜色

- `0% ~ 60%`：绿色。
- `60% ~ 80%`：黄色。
- `80% ~ 100%`：红色。
- 边界按左闭右开：`[0,60%)` 绿、`[60%,80%)` 黄、`[80%,100%]` 红。

### 3.4 数字与标题

- 标题只显示 `|z|` 取整，不加前缀（已澄清）。
- 隐藏规则（v1.3 新条目，代码已实现 `ZProgressHud.NUMBER_HIDE_RADIUS=16`）：`|z|≤16` 时只画进度条、不画数字；`|z|>16` 才绘制数字。

### 3.5 新旧替代

- 本条替代之前的 bossbar。旧的“只在边界前 32 格显示”逻辑作废。

## 4. 示例（只看条，不看血）

| 位置 | 去 / 回 | 条 |
|---|---|---|
| `\|z\|=16` 去程 | 去 | `6.25%` 绿，不显示数字（`\|z\|≤16` 隐藏） |
| `\|z\|=200` 去程 | 去 | `≈78%` 黄，显示 200 |
| `\|z\|=250` 去程 | 去 | `≈98%` 红，显示 250 |
| `\|z\|=256` | 去 | `0%`（新一段起点），显示 256 |
| `\|z\|=300` 去程 | 去 | `≈17%` 绿，显示 300 |
| `\|z\|=600` 去程 | 去 | `≈34%` 绿，显示 600 |
| `\|z\|=500` 回程 | 回 | `0%`（`into=244>128` 瞬时归零），显示 500 |
| `\|z\|=300` 回程 | 回 | `≈17%` 绿（前半段按公式），显示 300 |
| `\|z\|=300→500` 转头前进 | 去 | 按公式恢复（无锁存；500 处 `≈95%` 红），显示 500 |
| `\|z\|=200` 回程 | 回 | `0%`（`into=200>128` 瞬时归零），显示 200 |
| `\|z\|=200→190` 转头前进 | 去 | `≈74%` 黄，转头即恢复，显示 190 |
| `\|z\|=128` | 去 / 回 | `50%` 绿（公式自然值），显示 128 |
| `\|z\|=16` 回程 | 回 | `6.25%` 绿，不显示数字（隐藏区内按公式） |

## 5. 与扣血逻辑的边界

- 条不读取生命上限 / 层数，只读 `|z|` 和方向。
- 扣血逻辑不读取条的进度。
- 两边恰好共用 `128 / 256` 两个常数，但互不依赖。
